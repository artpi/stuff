stuff

Privacy

stuff is a static application. It has no application server, analytics, advertising, or account database of its own.

Where your data lives

Inventory records are stored in a Google Sheet in your Google Drive. Photos are stored in folders beside that Sheet. Depending on the inventory setting, a photo can remain private or be readable by anyone who obtains its individual link.

Google access

stuff asks for the per-file drive.file scope. This lets it access files it creates and files you explicitly choose with Google Picker; it does not grant access to all files in Drive.

Remembering access

By default, stuff stores Google's short-lived access token and exact expiration time in this browser's local storage so reopening the app is less disruptive. You can disable this option. A remembered token cannot be renewed by the static app and is removed before it expires, after an authorization rejection, or when you disconnect.

Any script that successfully executes on this website's origin could use a remembered token until it expires. stuff limits that risk with a restrictive Content Security Policy, no analytics or UI libraries, and text-only rendering of Sheet content. Do not use remembered access on a shared or untrusted device.

Public image URLs

If you add a public image URL, the browser requests that image directly from its host. The host can see network information such as your IP address. Public image content is not copied to Drive.

When link-shared Drive photos are enabled, stuff grants “Anyone with the link” read access to each uploaded original and thumbnail. The folders and inventory Sheet are not made public, but an individual image link can be forwarded and viewed without signing in.

Local device storage

The browser stores the selected spreadsheet ID, interface preferences, the remember-access preference, and—only when enabled—the temporary Google token and expiration time. The service worker caches only the public application shell, never Google API responses, tokens, inventory data, or private photos.

Disconnecting and revoking

“Disconnect inventory” removes the local connection without deleting Drive files. “Revoke Google access” also revokes the app's Google consent. You may additionally remove access in your Google Account security settings.
